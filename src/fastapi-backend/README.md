# Robot-IDE API (FastAPI backend)

FastAPI backend for the Robot-IDE application.

## Quick start
### 1) Prerequisites
- Python 3.12

### 2) Dependencies
Run the following command to install the required dependencies:
```bash
pip install -r requirements.txt
```

### 3) Unit tests
Run the following command to run all unit tests:
```bash
pytest -v
```

### 4) Backend start
Run the following command to start the API:
```bash
python3 main.py
```

## Code documentation tools
### 1) Swagger UI
Swagger UI enables code documentation and facilitates integration tests:
`http://localhost:8000/docs`

### 1) ReDoc
ReDoc enables code documentation in a modern web interface:
`http://localhost:8000/redoc`
